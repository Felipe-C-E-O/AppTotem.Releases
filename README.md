## Sobre o App
O appTotem tem como objetivo Ajudar o setor de atendimento facilitanto e otimizando o primeiro contato com o cliente

Como geralmente a atendente está oculpada com atendimento nos horários de muito movimento 

o apptotem vem para melhorar o fluxo de atendimento

o cliente chega na ex: clinica e ver o tablete para tirar uma senha
